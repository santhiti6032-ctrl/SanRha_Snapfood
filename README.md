# 🍊 SanRha_Snapfood

แอปถ่ายรูปอาหาร → ให้ ChatGPT บอกชื่อเมนูและแคลอรี่ → บันทึกว่าวันนี้กินอะไรไปบ้าง แล้วเทียบกับ TDEE ของคุณ
HTML / CSS / JavaScript ล้วน ไม่ต้องติดตั้งอะไร ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์

## เริ่มใช้งาน

1. ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์ (Chrome / Edge / Safari)
   - อยากใช้บนมือถือ: เปิดผ่านเว็บเซิร์ฟเวอร์ เช่น `npx serve .` หรือ `python -m http.server` แล้วเข้าจากมือถือในวง Wi-Fi เดียวกัน หรืออัปขึ้น GitHub Pages / Netlify
2. กรอก **น้ำหนัก** และ **ส่วนสูง** → แอปคำนวณ TDEE ให้ทันที
3. ใส่ OpenAI API key (สร้างได้ที่ https://platform.openai.com/api-keys) — เลือกได้ 2 แบบ
   - **ค่าเริ่มต้น (ไม่ต้องกรอกในแอป):** คัดลอก `config.example.js` เป็น `config.js` (ถ้ายังไม่มี) แล้วใส่ key ใน `OPENAI_API_KEY: 'sk-...'` บันทึกไฟล์ แล้วรีเฟรชแอป — `config.js` อยู่ใน `.gitignore` จึงไม่ถูก push ขึ้น GitHub
   - **กรอกในแอป:** แท็บ **โปรไฟล์** → วาง key → บันทึก (ถ้ากรอกตรงนี้ จะใช้แทนค่าใน `config.js`)
4. กดปุ่มกล้อง 📷 ตรงกลาง → ถ่าย/เลือกรูปอาหาร → ตรวจ/แก้ผลจาก AI → **บันทึกมื้อนี้**

ไม่มี key ก็ใช้ได้ด้วยปุ่ม **เพิ่มเอง** (กรอกชื่อเมนูและแคลอรี่เอง)

## ฟีเจอร์

- 📸 วิเคราะห์รูปด้วย OpenAI Vision (ค่าเริ่มต้น `gpt-4o-mini` เปลี่ยนได้ในหน้าโปรไฟล์) ได้ชื่อเมนูไทย ปริมาณ แคลอรี่ โปรตีน/คาร์บ/ไขมัน
- 🎯 วงแหวนแคลอรี่วันนี้เทียบ TDEE พร้อมสถานะ: ยังกินได้ / ใกล้ TDEE (±10%) / เกิน
- 🥩 แถบ Macros เทียบเป้า (โปรตีน 25% · คาร์บ 50% · ไขมัน 25% ของ TDEE)
- 📊 กราฟ 7 วันย้อนหลัง + ค่าเฉลี่ย + สตรีค + ประวัติแยกรายวัน
- 🌙 รองรับ Dark mode อัตโนมัติ, ออกแบบสำหรับมือถือเป็นหลัก

## วิธีคำนวณ TDEE

ใช้สูตร **Mifflin-St Jeor** (แม่นที่สุดในกลุ่มสูตรมาตรฐานสำหรับคนทั่วไป)

**1) BMR** — พลังงานที่ร่างกายใช้ตอนพักเฉยๆ

```
ชาย:  BMR = 10 × น้ำหนัก(kg) + 6.25 × ส่วนสูง(cm) − 5 × อายุ + 5
หญิง: BMR = 10 × น้ำหนัก(kg) + 6.25 × ส่วนสูง(cm) − 5 × อายุ − 161
```

**2) TDEE** = BMR × ตัวคูณกิจกรรม

| ระดับกิจกรรม | ตัวคูณ |
|---|---|
| นั่งทำงาน แทบไม่ออกกำลัง | 1.2 |
| ออกกำลังเบา 1–3 วัน/สัปดาห์ (ค่าเริ่มต้น) | 1.375 |
| ออกกำลังปานกลาง 3–5 วัน/สัปดาห์ | 1.55 |
| ออกกำลังหนัก 6–7 วัน/สัปดาห์ | 1.725 |
| หนักมาก / งานใช้แรง | 1.9 |

ผู้ใช้กรอกแค่น้ำหนักกับส่วนสูง ส่วน อายุ / เพศ / กิจกรรม ใช้ค่าเริ่มต้น **25 ปี · ชาย · ออกกำลังเบา** และแก้ได้ในหน้าโปรไฟล์ (หัวข้อ "ปรับให้แม่นขึ้น")

ตัวอย่าง: น้ำหนัก 65 kg, สูง 170 cm → BMR = 650 + 1,062.5 − 125 + 5 = **1,592.5** → TDEE = 1,592.5 × 1.375 ≈ **2,190 kcal/วัน**

- อยากลดน้ำหนัก: กินประมาณ TDEE − 500 kcal
- อยากเพิ่มน้ำหนัก/กล้าม: กินประมาณ TDEE + 300 kcal

## ข้อมูลที่เก็บใน localStorage

| key | เนื้อหา |
|---|---|
| `fs_profile` | น้ำหนัก ส่วนสูง อายุ เพศ ระดับกิจกรรม |
| `fs_meals` | รายการมื้ออาหาร (ชื่อ, แคล, macros, รูปย่อ 160px) |
| `fs_apikey` | OpenAI API key |
| `fs_model` | ชื่อโมเดลที่ใช้ |

## ⚠️ เรื่องความปลอดภัยของ API key

แอปนี้เรียก OpenAI ตรงจากเบราว์เซอร์ key จึงอยู่ในเครื่องของคุณ เหมาะกับการใช้ **ส่วนตัว** เท่านั้น
key ที่ใส่ใน `config.js` เป็นข้อความธรรมดา ใครเปิดไฟล์หรือเว็บนี้ได้ก็เห็น key — **อย่าอัป `config.js` ที่มี key ขึ้น GitHub / GitHub Pages / Netlify**
ถ้าจะเปิดให้คนอื่นใช้ ควรทำ backend เล็กๆ เป็นตัวกลางเก็บ key แทน และตั้ง usage limit ในหน้า OpenAI billing ไว้เสมอ

ค่าแคลอรี่จาก AI เป็นการประมาณจากรูป อาจคลาดเคลื่อนได้ แก้ตัวเลขได้ก่อนบันทึกทุกครั้ง
